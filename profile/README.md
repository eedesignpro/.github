# eedesignpro

Open-source tools for electrical engineering work: bench instrument control,
KiCad tools, and signal processing.

## Support

These projects are provided as-is. There is no support, no schedule, and no
promise to answer issues or pull requests. Some repositories are archived.
An archived repository is read-only.

## Ownership and license

Each repository states its copyright holder and its license in its `LICENSE`
file. Read that file before you use the code.
